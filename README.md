# cybersecurity-network-traffic-analysis
Machine learning analysis of cybersecurity network traffic using Python, Decision Trees and Random Forest models.

# Cybersecurity Network Traffic Analysis

**Module:** Fundamentals of AI and Data Science  
**Institution:** Technological University Dublin  
**Tools:** Python, Google Colab, scikit-learn

## Project Overview
This individual academic project explored the use of machine learning to identify malicious network activity.
I analysed 25,192 network traffic records containing 44 original features and developed classification and regression models to evaluate network attack patterns.

## Methodology
- Cleaned and prepared the network traffic dataset.
- Performed feature engineering and data preprocessing.
- Developed Decision Tree and Random Forest models.
- Evaluated classification performance using accuracy, precision, recall, F1-scores and confusion matrices.
- Applied five-fold cross-validation to assess model performance.

# Results
The Random Forest classification model achieved **99.80% test accuracy** on the academic dataset.
The analysis also identified limitations involving class imbalance and underrepresented attack categories, highlighting the importance of evaluating performance beyond overall accuracy.
